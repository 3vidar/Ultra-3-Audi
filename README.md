# Carlinkit Ultra 3 Driver Audi - V2

V8 dongle modification for wireless CarPlay with an existing Audi Virtual Cockpit CarPlay extension.

## Features

- Steering-wheel map zoom.
- Current street name and junction detail in the Virtual Cockpit.
- Double-OK switching between street and trip information, including arrival time and remaining distance when supplied by the Audi extension.
- Music, phone calls and reconnecting worked on the reference V8 setup.

## Install

1. Choose [macOS](macOS/) or [Windows](Windows/).
2. Download and extract the installer ZIP.
3. Follow the short README and included English PDF for your operating system.
4. Keep the backup folder created during installation.

The Audi cluster extension must already work with an iPhone connected directly by cable. These installers modify the dongle; they do not install the Audi extension.

Both packages are **Build Test** editions for matching Carlinkit Mini Ultra 3 hardware. They accept other builds when the required hardware layout and program files match. The adaptive installation flow, Windows execution and build **26022712.6238.2** have not been physically tested.
